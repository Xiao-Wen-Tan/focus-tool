# focus-data (private repo)

This folder is the source for the **private** GitHub repo `focus-data`. It is not
part of the public `focus-tool` repo and must never be merged into it.

## What this repo holds

`focus-data` holds only your task data, never any app code:

- `state.json`, your full task list, in the same format the desktop app keeps in
  `data/state.json`. This is the single shared copy that your phone and your
  desktop both read and write over the GitHub REST API.
- `day-plan.json`, the plan for a single day, made up of the time blocks the
  planner picked for your tasks, generated by the nightly job below or by the
  "Re-plan now" button in the app.

Because this repo holds your real tasks, it must stay private. Do not change it to
public, and do not copy its files into the public `focus-tool` repo.

## How the nightly job runs

`.github/workflows/replan.yml` (copied into this repo's root as
`.github/workflows/replan.yml`) runs automatically every night around 19:00
America/Chicago time. It:

1. Checks out this `focus-data` repo and the public `focus-tool` repo (for
   `planner.py`, the planning logic).
2. Runs the planner against `state.json` to build tomorrow's `day-plan.json`.
3. Commits and pushes the updated `day-plan.json`, if anything changed.

Before this will work in a real repo, open `.github/workflows/replan.yml` and
replace the placeholder `OWNER` in the `Checkout focus-tool` step with the GitHub
username or organization that owns the public `focus-tool` repo.

The job needs no secret token. It uses GitHub's own built-in repo permissions
(`contents: write`), which is why the workflow sets that permission explicitly.

## Running it by hand

You do not have to wait for the nightly run. From a terminal with the
[GitHub CLI](https://cli.github.com/) (`gh`) installed and signed in:

```
gh workflow run replan.yml --repo YOUR-GITHUB-USERNAME/focus-data -f mode=now
```

`mode` can be:

- `now`, plan the rest of today from the current time (rounded up to the next 5
  minutes), or tomorrow if it is already past 19:00.
- `tomorrow`, plan tomorrow regardless of the time.
- `auto`, the same check the nightly job itself uses, planning only if it is
  past 19:00 and tomorrow has not already been planned.

The same "Re-plan now" action is also available as a button inside the desktop
app and the phone web app; both call this same workflow through the GitHub API.

## Keeping your data private

Your task names, details and dates live only in this private repo and in your own
Box folder and phone. The public `focus-tool` repo never receives a copy, and the
`check_public.py` safety check in `focus-tool` is there specifically to stop that
from happening by accident.
